# Система реєстрації та посадки на рейс

Навчальна практика, спеціальність F2 «Інженерія програмного забезпечення».
Варіант 3. Мова: C++ (ООП).

## Збірка

```
cmake -S . -B build
cmake --build build
```

Запуск: `build/flight_checkin` (на Windows — `build\Debug\flight_checkin.exe` або `build\flight_checkin.exe`).

## Етапи процесу

Реєстрація пасажира → вибір місця → здача багажу → контроль і допуск до посадки.
Рейс може бути затриманий.
